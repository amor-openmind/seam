seam.

Two things to grant, once. Then push your pointer off the edge of this screen and it appears on the next machine.

✓
Watch the mouse and keyboard
Granted in Privacy & Security › Input Monitoring. Without it seam sees nothing at all.
● granted to this build
2
Hold input back from this machine
Granted in Privacy & Security › Accessibility. This is the one that makes seam a switch rather than a mirror.
○ not granted — typing would land on both machines at once
Why this one is easy to miss: without it macOS still lets seam see input, and forwarding looks perfect — while this machine keeps acting on the same keystrokes. Nothing reports an error.
3
Restart seam
macOS does not apply either permission to a program that is already running.
4
Start seam on another machine
Paired machines find each other and connect on their own — no addresses, no ports.

Every update asks again. macOS ties these permissions to the exact binary, so a new download starts with none. That is the rule, not a bug — seam will say so plainly when it happens.
