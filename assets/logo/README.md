# seam logo

The mark represents two machines meeting at a shared boundary. The three orange bars
are the seam: the hand-off point where input crosses without the user noticing.

All PNG exports are RGBA with transparent backgrounds. The production colors are
indigo `#2B4685` and thread orange `#B04517`.

## Generation provenance

The selected source was created with the built-in image-generation workflow and then
normalized locally to the exact production colors, transparent edges, consistent
padding, and platform sizes.

Final generation prompt:

> Create one highly distinctive abstract geometric logo mark for “seam,” a
> cross-platform desktop utility that lets one pointer and keyboard move continuously
> between computers. Use two interlocking indigo bracket-like forms facing each other
> across a narrow vertical join. Bridge the join with three small thread-orange
> rectangular stitch marks. A clean horizontal negative-space channel should imply
> continuity but must not form an arrow. Use an ultra-minimal, flat, vector-friendly
> style with Swiss precision, a bold silhouette, exact deep indigo `#2B4685` and thread
> orange `#B04517`, no text, gradients, shadows, realistic screens, input-device
> imagery, chain links, infinity symbols, app-tile container, or presentation mockup.
